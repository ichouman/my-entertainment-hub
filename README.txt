# My Entertainment Hub — Version 3

## Upload to GitHub Pages
1. Before updating your current website, open Settings -> Export backup and save the JSON file.
2. On your iPhone or iPad, download `index.html` from this archive and save it to Files.
3. Open your GitHub repository, `my-entertainment-hub`, and the existing root-level `index.html` file.
4. Tap Edit (pencil) and replace its contents with those of this file, then commit to `main`. Alternatively, upload the new `index.html` at the repository root and confirm replacement if GitHub offers it.
5. Open the existing GitHub Pages website and reload. If you added it to your Home Screen, close and reopen the app.
6. In Library -> Season & episode tracker, pick a TV show and track episodes.

## What's new
- Per-show episode tracking by season, progress bars, next unwatched episode, whole-season marking, and manual/offline season counts.
- Free TVmaze public API: https://www.tvmaze.com/api (CC BY-SA, credited in the interface).
- Episode progress is preserved using the V1/V2 storage key and included in export/import backups.
- No sign-in, subscription, or Mac server required. No actual TV streaming supplied.

## Notes
- Metadata and episode dates are informational and can vary by region/service.
- Data is local to each device and browser installation; use backup transfer to sync manually.
- Do not clear Safari website data unless you've exported a backup.
- GitHub Pages uses the index.html from the site root; there are no extra files needed.
