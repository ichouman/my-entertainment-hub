MY ENTERTAINMENT HUB — MOVIE & TV CATALOG UPGRADE (v2)

WHAT'S NEW
- New Catalog tab in desktop/iPad and iPhone navigation.
- 22 curated movie and TV picks with genres, details and poster placeholders.
- Online metadata and cover images from TVmaze (shows) and Wikipedia (films), where available.
- Search both sources when online without creating accounts or API keys.
- Add titles to your watchlist and update the watched/in-progress status.
- Existing Discover, favorites, local player, and backups remain available.

HOW TO INSTALL ON YOUR EXISTING GITHUB PAGES SITE
1. (Optional safety backup) On your current site select Settings > Export backup, and save to Files.
2. On iPad/iPhone Safari, open github.com > your existing my-entertainment-hub repository > Code.
3. Select Add file > Upload files.
4. Select the NEW index.html included in this package. Upload it to the same directory as your original index.html, at the repository root.
5. Commit changes directly to your existing main branch. The same-name file replaces the old version.
6. Reopen your existing published site and refresh. Wait a few minutes for GitHub Pages to deploy.
7. The Catalog tab should appear. No new Pages setup or domain is required.

KEEP YOUR DATA
The old and new version share the same localStorage key (my_entertainment_hub_v1).
On the same browser/origin, saved data is kept through normal page refreshes and file updates.
Safari and Home Screen apps may maintain separate storage. For transferring data between
installations or devices, use Settings > Export backup then Settings > Import backup.
Import REPLACES the existing list in the receiving installation, so back it up first.

LIMITATIONS
- Static GitHub Pages site, no Jellyfin server required yet.
- Search and live posters require internet and source accessibility; some thumbnails may be absent.
- No automatic cross-device sync.
- Information in the catalog does not promise a title is free to watch.
- This app opens official services externally and does not provide protected video streams.
